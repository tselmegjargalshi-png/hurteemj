# Хүртээмжийн тайлан

Зорилтот түвшин: **WCAG 2.2 AA**. Энэ тайлан юу шалгагдсан, юу шалгагдаагүйг ил тод бичнэ.

## Автомат шалгалт (axe-core, `npm run test:e2e`)

`tests/e2e/a11y.spec.ts` нь дараах хуудсуудыг axe-core-ийн `wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa` дүрмээр шалгадаг. Зөрчил байвал тест унана.

Нүүр, дэлгүүр, ангилал, нэвтрэх, бүртгүүлэх, хүртээмжийн тохиргоо, тусламж, сагс, төлөв, хүртээмжийн мэдэгдэл, нууцлал, төлбөрийн нөхцөл, үйлчилгээ, 404, мөн **өндөр ялгаралт + маш том үсэг** горимд нүүр хуудас.

Бодит урсгалын дунд (`commerce.spec.ts`) шалгагдсан хуудас: хайлтын үр дүн, бүтээгдэхүүний дэлгэрэнгүй, сагс, алдаатай бүртгэлийн маягт, checkout, захиалгын хуудас, админ захиалга, мэдэгдлүүд.

Үр дүн (сүүлийн ажиллуулалт): **24/24 тест өнгөрсөн**, axe зөрчил 0.

## Тестээр олдож засагдсан бодит алдаа

1. Нэг хуудсанд хоёр маягт байхад талбарын `id` давхардаж, нэг `select` шошгогүй болж байсан. Одоо `id` маягт бүрт өвөрмөц (`useId`).
2. Холбоос ба `.btn-primary` өнгө CSS layer-ийн дарааллаас болж зөрчилдөж, өндөр ялгаралтай горимд товчны текст ялгарал дутаж байсан.
3. Нэмэлт тайлбарын текст (`sr-only`) нь товчны нэрэнд "Хасах : Бараа" гэж зайтай уншигдаж байсан.

## Гараар хэрэгжүүлсэн зарчим

- Семантик HTML: `header`, `nav` (нэрлэсэн), `main`, `footer`, гарчгийн шатлал, `lang="mn"`.
- «Үндсэн агуулга руу шилжих» холбоос; бүх үйлдэл гараар хийгдэнэ; drag-and-drop байхгүй; харагдахгүй CAPTCHA байхгүй.
- Маягт: бүх талбар `label`-тэй, заавал/заавал биш тэмдэглэгээ, зөвлөмж `aria-describedby`, алдаа `aria-invalid` + алдааны хураангуй (`role="alert"`, фокус шилжинэ, хураангуйн холбоос талбар руу аваачна).
- Амжилт/алдаа/сагсны өөрчлөлтийн мэдэгдэл `role="status"` (live region).
- Өнгө: текст ≥ 4.5:1, хил/UI ≥ 3:1; өндөр ялгаралт, том үсэг (120%/140%), том товчлуур (56px), тод фокус, хөдөлгөөн багасгах (`prefers-reduced-motion` ба хэрэглэгчийн сонголт), холбоос доогуур зураастай.
- Томруулалтыг хориглоогүй (`viewport`-д `user-scalable` байхгүй).
- Үнийг `aria-hidden` «₮» + `sr-only` «төгрөг» хэлбэрээр дэлгэц уншигчид зөв уншуулна.
- Зураг: админ alt тайлбар **заавал** оруулна (ихэвчлэн шалгагдсан); AI-аар бүтээсэн зургийг тэмдэглэнэ.
- Тохиргоо нэвтэрсэн хэрэглэгчид DB-д, зочинд cookie-д хадгалагдана.

## Шалгагдаагүй / мэдэгдэж буй хязгаарлалт

- **Дэлгэц уншигчаар (NVDA, JAWS, VoiceOver, TalkBack) гараар туршаагүй.** Автомат шалгалт WCAG-ийн ~30-40%-ийг л илрүүлдэг. Бодит хэрэглэгчтэй туршилт шаардлагатай.
- Хараагүй, сонсголгүй, гарын хөдөлгөөний хязгаарлалттай бодит хэрэглэгчийн туршилт хийгдээгүй.
- Дуугаар хайх нь хөтчийн Web Speech API-д (Chrome/Edge/Safari) тулгуурлана; Монгол хэлний таних чанарыг баталгаажуулаагүй; Firefox дэмжихгүй (товч харагдахгүй).
- Нүдний хөдөлгөөн, толгойн удирдлага, switch control: платформ эдгээрийг өөрөө хэрэгжүүлэхгүй; төхөөрөмж/ҮС-ийн дэмжлэгт тулгуурлан стандарт HTML ашиглан саад болохгүй байхыг зорьсон. Туршаагүй.
- Видео, хадмал, дохионы хэлний контент хараахан байхгүй. Дохионы хэлний автомат орчуулга байхгүй, байхгүй гэж тусгайлан бичсэн.
- Хүргэлтийн мэдэгдэл сайт доторх бичгээр л байна (SMS/имэйл холбогдоогүй).
- Контрастыг зөвхөн axe-ээр, өнгөний токенуудаар шалгасан; Windows High Contrast Mode гараар туршаагүй.
